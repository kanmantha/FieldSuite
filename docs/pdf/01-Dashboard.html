Dashboard

Your daily operations snapshot, in one screen

Purpose

The Dashboard is the first screen after signing in. It condenses every module into a set of live numbers plus automated alerts, so you can see what needs attention without opening each module.

Key functions

  • Live KPI cards — active projects, open incidents, overdue actions, active permits, open snags, attendance today, expiring documents, pending approvals, open NCRs, estimates sent.
  • Red / amber cards draw attention to problems (e.g. overdue actions).
  • Smart Nudges list with severity, kind and one-click Review links.
  • Shortcut to the AI Assistant from the page header.

How to use it

  1. Review the KPI row to spot anything red or rising.
  2. Scan Smart Nudges and click Review to jump straight to the record.
  3. Use the sidebar to open a module for detail.
Tip: KPI cards are click-free by design — numbers always refresh from live data, including alerts generated when actions go overdue.
