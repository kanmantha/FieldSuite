AI Assistant

Ask about your data · auto-draft records

Purpose

The Assistant makes FieldSuite faster to operate. It answers questions drawn from your own project data and produces structured entry drafts from plain-text notes. It is designed to work offline by default (rules-based, no data leaves your workspace), with an LLM enhancement only when configured.

Key functions

  • Ask — ask questions about incidents, permits, snags, estimates and attendance; answers cite your organization’s data.
  • Draft — turn a rough note into a structured incident / snag / NCR entry (title, description, category, severity).
  • UsedLlm flag — the reply indicates whether the response came from the offline rules engine or the configured LLM.
  • Drafts are for review — you save them through the normal module forms.

How to use it

  1. Open AI Assistant in the sidebar.
  2. Type a question such as “Which permits are awaiting approval?” and view the answer.
  3. Paste a rough note and pick Draft type to get a structured entry; copy it into the module form and adjust if needed.
Privacy note: offline mode means your data is processed by the rules engine within your workspace. Enable an LLM only if your organization accepts cloud processing.
