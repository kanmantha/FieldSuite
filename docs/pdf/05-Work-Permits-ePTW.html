Work Permits (ePTW)

Electronic permit-to-work with risk-based approvals

Purpose

Digitalize the permit-to-work process: request, review, approve, execute, suspend and close — with the approval chain matched to the assessed risk of the activity.

Key functions

  • Permit types and work description per task.
  • Risk-based approval chain — higher-risk work requires more senior approval levels automatically.
  • Checklist items to be confirmed before work starts (e.g. area cleared, extinguishers staged).
  • Full lifecycle: submit, approve/reject, start, suspend, resume, close.
  • Approval history and comments kept on every permit.

How to use it

  1. Open Work Permits (ePTW) and Create a permit for the activity.
  2. Add the required checklist items and submit.
  3. Approvers review and decide; pending approvals appear on the dashboard.
  4. Once approved, Start the permit — and Suspend / Resume / Close as the work dictates.
Tip: suspend a permit whenever conditions change (weather, isolations, staffing) — resuming re-activates the same approval record instead of a re-submission.
