Estimation & BOQ

Estimates, bills of quantities and proposals

Purpose

Build project estimates quickly as category-based bills of quantities, get rate suggestions, and produce a clean proposal view for clients — all in one place.

Key functions

  • Estimates per project with status tracking (draft to sent).
  • Categories with BOQ line items (description, quantity, unit, rate, amount).
  • Rate suggestions to speed up pricing of familiar items.
  • Category and item totals computed live.
  • Proposal page — a clean, print-ready summary for the client.

How to use it

  1. Open Estimates & BOQ and Create an estimate for a project.
  2. Add categories, then line items under each.
  3. Use Suggest rate where you want a starting price, then adjust.
  4. Mark the estimate as sent when it goes to the client.
  5. Open the Proposal view and print / save as PDF.
Tip: the proposal page is designed for printing — use the browser’s Print / Save as PDF to send a clean quotation.
