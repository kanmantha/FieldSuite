Projects

The register that scopes your site records

Purpose

Projects form the backbone of the platform. Incidents, snags, inspections, permits, estimates and attendance are all linked to a project, so history stays organized per site or job.

Key functions

  • Create and edit projects (name, details, active status).
  • Project list with status at a glance.
  • Project detail page showing core record.
  • Every related record references the project for reporting.

How to use it

  1. Open Projects in the sidebar.
  2. Click Create, enter the project name and details, and save.
  3. Select the project when creating incidents, permits, estimates, etc.
Tip: keep project names consistent with site names / contract numbers so records stay easy to find and report on.
